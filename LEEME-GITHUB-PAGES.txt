SPIDEY NETWORK - VERSION ESTATICA

1. Elimina del repositorio los archivos anteriores o crea un repositorio limpio llamado spidey.
2. Descomprime el archivo ZIP entregado por Codex.
3. Sube TODOS los archivos y carpetas directamente a la raiz de la rama main.
4. Deben verse index.html, .nojekyll, _next, hero-command.png y world-map.png.
5. En Settings > Pages selecciona Deploy from a branch.
6. Elige main, /(root) y presiona Save.
7. No uses GitHub Actions para esta version.
